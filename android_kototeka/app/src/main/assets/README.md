# 🐾 «Кототека 2.0» — Коллекция городских котов

## ✨ Что нового в Кототеке 2.0

1. **🎨 Премиальный нативный дизайн (Apple-inspired)**:
   - Тёплая молочная палитра для светлой темы (`#F7F5F0`) и глубокий графит для тёмной темы (`#121316`).
   - Идеальная геометрия, плавная анимация bottom sheet и аккуратные шрифты SF-style.
2. **🐱 Фирменный логотип**:
   - Минималистичный знак, объединяющий кошачьи ушки и видоискатель фотокамеры.
3. **📸 Retina-качество фото**:
   - Полноразмерные снимки сохраняются с разрешением до **2560px** без потери деталей.
   - Квадратные превью генерируются в высоком разрешении **640×640px** с аппаратным сглаживанием.
4. **🔍 Полноэкранный просмотр фото**:
   - Тапните по фото в карточке котика, чтобы рассмотреть оригинал на весь экран в высоком разрешении.
5. **🎛️ Нативная панель фильтров и сортировки**:
   - Вместо горизонтальной ленты тегов — аккуратный нативный bottom sheet.
   - Фильтрация по окрасу, характеру, типу локации (GPS / вручную).
   - Сортировка: новые, старые, по кличке (А-Я, Я-А).
6. **🔲 Переключатель вида коллекции**:
   - Переключение в 1 клик между компактной сеткой в 2 колонки и крупными карточками в 1 колонку.
7. **✏️ Редактирование карточек котиков**:
   - Возможность в любой момент отредактировать имя котика, дату и время встречи, адрес и заметки.
8. **🖼️ Открытка котика 2.0 и экспорт в Telegram**:
   - Генерация стильной дизайнерской открытки в высоком разрешении (PNG).
   - Прямой шеринг фото и описания в Telegram со ссылкой на приложение.
9. **📍 Защита от сбоев GPS и спуфинга**:
   - Автоматическое извлечение координат и даты из метаданных EXIF фотографии.
   - Двойной режим: спутниковый GPS или ручной выбор точки на карте города с автопоиском адреса.
10. **💾 100% Offline и резервное копирование**:
    - Вся коллекция хранится локально в IndexedDB без необходимости доступа к серверу.
    - Экспорт и импорт всей базы в один клик.

## 🛠️ Локальный запуск (PWA / Web)

### Запуск на Mac в 1 клик:
Дважды кликните по файлу **`run_kototeka.command`** в папке проекта.
Откроется окно терминала с адресами:
- Компьютер: `http://localhost:8088`
- Телефон в той же Wi-Fi сети: `http://<ваш-локальный-ip>:8088`

### Запуск через консоль:
```bash
python3 kototeka/server.py
```
